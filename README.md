# Python Assignments

A collection of Python programming assignments and practice programs developed to strengthen fundamental programming concepts, problem-solving skills, and logical thinking.

## 📌 About

This repository contains Python programs covering basic to intermediate programming concepts. The assignments focus on implementing solutions using clean, simple, and understandable Python code.

The repository is organized assignment-wise to make the programs easy to navigate and review.

▶️ How to Run

1. Clone the repository
git clone https://github.com/prabhanjaningle/Python_Assignments.git

2. Navigate to the repository
cd Python_Assignments

3. Navigate to an assignment
cd Assignment_1

4. Run a Python program
python3 Factor.py

Replace Factor.py with the name of the program you want to execute.
